User Dashboard

Database

SQLite via SQLAlchemy ORM. Tables: analyses, scan_logs, threat_feed. JSON columns store category scores, MITRE mappings and IOC lists.

Tech Stack

Frontend: HTML/CSS/JS SPA. Backend: Python FastAPI + Pydantic. ORM: SQLAlchemy. Server: Uvicorn ASGI.

Data Sources

Keyword/NLP classifier inspired by the MITRE CTI corpus and BERT-spaCy hybrid research, extended with regex-based IOC/CVE extraction.

LITERATURE REVIEW

MITRE CTI Repository

github.com/mitre/cti — canonical ATT&CK technique taxonomy used for mapping.

Our Improvement: real-time technique mapping served via REST API instead of static lookup tables.

BERT-spaCy Hybrid CTI

doi.org/10.1038/s41598-025-34505-2 — hybrid NLP classification for threat text.

Our Improvement: lightweight, dependency-free rule-weighted classifier deployable without GPU, with a persistence layer for auditability.

PLATFORM FEATURES

NLP Threat Classification

Classifies free-text threat reports into categories (Ransomware, APT, Phishing, DDoS, Insider, Malware).

Risk Level Prediction

Assigns HIGH / MEDIUM / LOW risk with confidence scoring, persisted to SQLite.

IOC Extraction

Regex-based extraction of IPs, domains, hashes, CVEs and emails from raw text.

MITRE ATT&CK Mapping

Maps detected threat categories to relevant MITRE technique IDs.

Historical Analysis

Every analysis and scan is stored in the database and retrievable via API.

Real-Time Dashboard

Live metrics, feed and charts computed directly from database aggregates.
